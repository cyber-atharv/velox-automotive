# 🏎️ VELOX Automotive — 3D Interactive Performance Showcase

An ultra-luxury, high-performance interactive automotive web showcase featuring fluid canvas-based scroll animations, WebGL shaders, responsive telemetry readouts, and multi-vehicle product exploration.

---

## 🌐 Live Demo

Experience the live application here:  
👉 **[https://cyber-atharv.github.io/velox-automotive/](https://cyber-atharv.github.io/velox-automotive/)**

## 🚀 Showcased Machines

1. **GT-X Supercar** (`/car`):
   - **Powertrain**: 4.0L Twin-Turbo V8
   - **Output**: 750 HP | 850 Nm Torque
   - **Acceleration**: 0-100 km/h in 2.8s
   - **Features**: Active aerodynamics, carbon-ceramic braking, dual-clutch transmission.

2. **RS1 MotoRacer** (`/moto`):
   - **Powertrain**: 998cc Inline-4
   - **Output**: 220 HP | 14,500 RPM
   - **Top Speed**: 312 km/h
   - **Features**: Carbon chassis, race telemetry dashboard, titanium exhaust.

3. **LX1 Hypercar** (`/legend`):
   - **Powertrain**: 6.5L Naturally Aspirated V12 + Quad-E-Motors
   - **Output**: 1,200 HP
   - **Acceleration**: 0-100 km/h in 1.9s
   - **Production**: Limited to 25 bespoke examples worldwide.

---

## ✨ Engineering & Highlights

- **Scroll-Driven 60FPS Canvas Scrub**: High-resolution frame-by-frame scrubbing using HTML5 Canvas & GSAP ScrollTrigger.
- **Custom Shaders**: Hardware-accelerated dynamic grain and light blooms via `@paper-design/shaders-react`.
- **Multi-Vehicle Navigation**: Seamless routing across distinct vehicle landing experiences.
- **Responsive Telemetry & Specs**: Interactive data grids, metric cards, and engineering breakdowns.

---

## 🛠️ Built With

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Static Export)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: [GSAP](https://greensock.com/gsap/) (ScrollTrigger)
- **Shaders**: WebGL Canvas Shaders
- **Hosting**: GitHub Pages

## 💻 Local Development

1. Clone repository:
   ```bash
   git clone https://github.com/cyber-atharv/velox-automotive.git
   cd velox-automotive
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Build static export for production:
   ```bash
   npm run build
   ```
